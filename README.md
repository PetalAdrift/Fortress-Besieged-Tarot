# Fortress Besieged Tarot 🔮

This suit of tarot cards is inspired by *Fortress Besieged*, a novel by Qian Zhongshu. [Find your tarot readings.](https://petaladrift.github.io/Fortress-Besieged-Tarot/)

Web version designed and coded by [Hannah](https://github.com/Hannah-Fan0) and [Petal Adrift](https://github.com/PetalAdrift).

## hosting your own tarot pages

Please feel free to clone this repo for your own suits of tarot cards. Note that you will need to replace copyright-protected content with your own. In fact, that is all you need to do before you can successfully run your own page.

If you are using this code on a local machine, you *might* need to host a local server for it to work. There are many ways to do this. For example, you may use VS Code Live Server or run ``python3 -m http.server``.
